# محفظتي — تطبيق أندرويد للدخل والمصاريف والديون

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لمتابعة الدخل والمصاريف والديون،
بواجهة عربية كاملة من اليمين إلى اليسار، ويعمل بدون إنترنت وبدون حسابات —
كل البيانات محفوظة في قاعدة بيانات SQLite على الجهاز.

## المزايا

| القسم | التفاصيل |
|---|---|
| الرئيسية | الرصيد الإجمالي، دخل ومصروف الشهر، أرصدة المحافظ، ملخص الديون، أحدث العمليات |
| العمليات | دخل / مصروف / تحويل بين المحافظ، بحث، فلترة بالنوع، تنقّل بين الشهور، تجميع باليوم |
| التقارير | توزيع المصروفات والدخل على التصنيفات بالنِسَب، مخطط آخر ٦ أشهر، متابعة الميزانيات |
| الديون | «لي عند الآخرين» و«عليّ للآخرين»، سداد دفعات جزئية، تاريخ استحقاق مع تنبيه التأخير، سجل الدفعات |
| المحافظ | محافظ متعددة (نقدي، بنك، محفظة إلكترونية…) برصيد افتتاحي ولون ورمز، أرشفة أو حذف |
| التصنيفات | تصنيفات دخل ومصروفات قابلة للتعديل، مع ميزانية شهرية اختيارية لكل تصنيف |
| الإعدادات | رمز العملة (أو رمز مخصص)، المظهر (فاتح/داكن/حسب النظام)، تصدير CSV، حذف البيانات |

تصنيفات ومحافظ افتراضية جاهزة تُنشأ تلقائيًا عند أول تشغيل.

## تنزيل ملف APK الجاهز

البناء يتم تلقائيًا عبر GitHub Actions:

1. افتح تبويب **Actions** في المستودع.
2. اختر تشغيل **«بناء تطبيق محفظتي (APK)»** الأحدث (أو اضغط *Run workflow* يدويًا).
3. نزّل الملف المضغوط **Mahfazti-APK** من قسم *Artifacts*، واستخرج منه `Mahfazti-*.apk`.
4. على الهاتف: فعّل «تثبيت من مصادر غير معروفة» ثم افتح الملف للتثبيت.

ولإصدار رسمي: أنشئ وسمًا (tag) يبدأ بحرف `v` مثل `v1.0.0` ودفعه، فيُرفق الـAPK تلقائيًا في Releases.

## البناء محليًا

يتطلب JDK 17 و Android SDK (أو Android Studio):

```bash
cd android-wallet
./gradlew :app:assembleRelease     # الناتج: app/build/outputs/apk/release/app-release.apk
./gradlew :app:assembleDebug       # نسخة تطوير بمعرّف com.mahfaza.wallet.debug
```

## التوقيع

المشروع يستخدم مفتاحًا ثابتًا موجودًا في `keystore/mahfazti.jks` (كلمة المرور `mahfazti`)
حتى تثبّت التحديثات فوق النسخة القديمة دون حذف التطبيق وبياناته.
هذا المفتاح للاستخدام الشخصي فقط — لنشر التطبيق على Google Play أنشئ مفتاحك الخاص
واستبدل بيانات `signingConfigs` في `app/build.gradle.kts`.

## البنية التقنية

```
android-wallet/
├─ app/src/main/java/com/mahfaza/wallet/
│  ├─ MainActivity.kt , WalletApp.kt
│  ├─ data/        Models.kt · AppDb.kt (SQLite) · Repository.kt
│  ├─ ui/          AppRoot.kt (التنقّل) · theme/ · common/ · screens/
│  └─ util/        Fmt.kt (تنسيق المبالغ والتواريخ بالعربية)
└─ keystore/mahfazti.jks
```

- `minSdk 24` (أندرويد 7) و `targetSdk 35`
- لا توجد أي أذونات في الـManifest، ولا اتصال بالشبكة
- قاعدة البيانات: `mahfazti.db` — الجداول: `wallets`, `categories`, `txns`, `debts`, `debt_payments`, `prefs`
