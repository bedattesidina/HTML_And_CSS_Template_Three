# مدير المال — Money Manager

تطبيق ويب بسيط لتسجيل المصاريف والمداخيل، مبني بـ HTML/CSS/JavaScript فقط، بدون أي مكتبات خارجية.
يمكن **تنصيبه على الجوال** (PWA) و**يعمل بدون إنترنت**، وكل البيانات تبقى داخل جهازك (localStorage) ولا تُرسل لأي خادم.

## المزايا

- تسجيل سريع للمصروف والمدخول مع لوحة أرقام وفئات جاهزة (أكل، نقل، فواتير، صحة وعلاج، تعليم…).
- **حسابات متعددة**: المصاريف اليومية، الطوارئ والعلاج، الاستثمار… مع رصيد لكل حساب وتحويل بينها.
- **ميزانية شهرية لكل فئة** مع أشرطة تقدّم وتنبيه فوري عند الاقتراب من الحد أو تجاوزه.
- تقرير شهري: المداخيل، المصاريف، المتبقّي، وتوزيع المصاريف حسب الفئة (رسم أو جدول).
- العملة قابلة للتغيير، والافتراضي **MRU (الأوقية)**.
- بداية شهر مالي قابلة للضبط (مثلاً من اليوم 25 إذا كان الراتب حينها).
- نسخ احتياطي: تصدير/استيراد JSON، وتصدير CSV.
- مظهر فاتح/داكن.

## التشغيل

افتح `money-manager/index.html` عبر خادم محلي (الـ Service Worker لا يعمل من `file://`):

```bash
cd money-manager
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو افتحه من الاستضافة عبر GitHub Pages: `https://<اسم-المستخدم>.github.io/HTML_And_CSS_Template_Three/money-manager/`

## التنصيب على الجوال

- **Android / Chrome**: افتح الرابط ← قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»
  (أو زر «تنصيب التطبيق» داخل صفحة الإعدادات).
- **iPhone / Safari**: افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التنصيب يعمل التطبيق بدون إنترنت تمامًا.

## ملاحظة عن البيانات

البيانات محفوظة في هذا المتصفح/الجهاز فقط. حذف بيانات المتصفح يحذفها،
لذلك صدّر نسخة JSON من وقت لآخر من صفحة الإعدادات.
